# Claude entry point

Before working in this repository, read and follow [AGENTS.md](AGENTS.md).
It is the canonical shared contributor guide; do not duplicate its rules here.

Then read:

1. [PRD.md](PRD.md) for requirements and proposed milestone boundaries.
2. [ARCHITECTURE-ESSENTIALS.md](ARCHITECTURE-ESSENTIALS.md) for quick orientation.
3. [ARCHITECTURE.md](ARCHITECTURE.md) for proposed technical boundaries.
4. [DESIGN.md](DESIGN.md) for screen references and UI constraints.
5. [DECISIONS.md](DECISIONS.md) for choices and open decisions.

The current repository contains static StudyMate design references, not a completed
upload-and-generate platform. Provider, backend and native-app selections are open.
Preserve the exports, distinguish mock data from actual behavior, and report only
checks performed. Current user instructions and higher-priority rules take precedence.
